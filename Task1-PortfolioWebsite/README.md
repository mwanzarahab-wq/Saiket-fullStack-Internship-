# Task 1: Static Portfolio Website

SaiKet Systems Full Stack Development internship, Task 1.

A responsive, themed portfolio website with a homepage, an About section, a Projects section of placeholder cards, and a contact form with JavaScript validation. Styled with Bootstrap 5.

## Features
- Sticky, responsive navigation bar with scroll highlighting
- Homepage hero with call-to-action buttons
- About section with skills and quick facts
- Projects section with placeholder cards (to be replaced with real projects)
- Contact form with JavaScript validation:
  - Name: at least 2 characters
  - Email: must be a valid address
  - Subject: at least 3 characters
  - Message: at least 10 characters, 500 maximum, with a live character counter
  - Inline error messages that update as you type
- Light and dark theme toggle, remembered between visits
- Fully responsive on phones, tablets and desktops

## Tech Stack
HTML5, CSS3, Bootstrap 5.3, JavaScript (Vanilla)

## Notes
The contact form validates input in the browser. Because this is a static site, it does not send the message anywhere yet. Sending would need a server or a form service, which is covered later in the internship.
